# لوحة تحكم تكامل فواتير الفوترة من Oracle إلى SAP B1

يوفر هذا المشروع لوحة تحكم قائمة على الويب لمراقبة وإدارة تكامل الفوترة بين قاعدة بيانات Oracle و SAP Business One.

## حالة المشروع

توجد لوحة التحكم حالياً في حالة مستقرة مع الميزات الرئيسية التالية المطبقة:

- **إدارة البيانات المركزية**: تم تطبيق React Context مشترك (`OracleDataProvider`) لجلب وإدارة البيانات من قاعدة بيانات Oracle. هذا يضمن تحميل البيانات مرة واحدة فقط وتوفرها لجميع المكونات، مما يحسن الأداء ويقلل من استدعاءات API المكررة.
- **المكونات القابلة لإعادة الاستخدام**: تم إعادة هيكلة مكون `DashboardStats` ليكون مكوناً عرضياً بحتاً، يتلقى جميع بياناته عبر props. هذا يجعله قابلاً لإعادة الاستخدام بدرجة عالية ومنفصلاً عن منطق جلب البيانات.
- **عروض البيانات الشاملة**:
  - **تبويب النظرة العامة** الذي يعرض مؤشرات الأداء الرئيسية وإحصائيات صحة النظام.
  - **تبويب بيانات Oracle** الذي يوفر عرضاً مفصلاً ومقسم إلى صفحات وقابلاً للتصفية للبيانات المالية الخام.
- **تنسيق العملة الديناميكي**: تم تكوين التطبيق لعرض جميع القيم المالية بالجنيه المصري.
- **معالجة الأخطاء القوية**: تم تصميم الواجهة الأمامية للتعامل مع أخطاء الاتصال بـ API بأسلوب سلس وتوفر للمستخدمين خيار إعادة المحاولة يدوياً.

## التحديثات الأخيرة

- **إصلاح خطأ (الأصفار في النظرة العامة)**: تم إصلاح خطأ حرج حيث كان مكون `DashboardStats` يعرض قيم صفرية في تبويب النظرة العامة. تم حل هذا من خلال ضمان تلقي المكون للبيانات الصحيحة من السياق المشترك.
- **إعادة هيكلة المعمارية**: تم نقل جميع منطق جلب البيانات من المكونات الفردية إلى `OracleDataProvider` المركزي، مما يبسط منطق المكونات ويحسن القابلية للصيانة.
- **استمرارية البيانات عبر التبويبات**: تم تطبيق نموذج حالة مشترك يمنع إعادة جلب البيانات في كل مرة ينتقل فيها المستخدم بين تبويبي "النظرة العامة" و "بيانات Oracle".

## تكامل SAP B1

يتضمن هذا المشروع ميزة لتكامل بيانات الفوترة من قاعدة بيانات Oracle إلى SAP Business One كقيود يومية.

### مزامنة SAP

يمكن تشغيل عملية مزامنة SAP من خلال إرسال طلب POST إلى نقطة النهاية `/api/sap/sync`. هذا سيقوم بـ:
1.  استخراج أحدث بيانات الفوترة من قاعدة بيانات Oracle.
2.  تجميع البيانات حسب الفرع.
3.  إنشاء قيد يومي منفصل لكل فرع.
4.  نشر القيود اليومية إلى طبقة الخدمة في SAP Business One.

**لتشغيل المزامنة:**
```bash
curl -X POST http://localhost:3000/api/sap/sync
```

### التكوين

للاتصال بـ SAP Business One، تحتاج إلى توفير متغيرات البيئة التالية في ملف `.env.local`:

```
SAP_SERVICE_LAYER_URL=https://<your-sap-server>:50000/b1s/v1
SAP_COMPANY_DB=<your-company-db>
SAP_USERNAME=<your-sap-username>
SAP_PASSWORD=<your-sap-password>
```

### تكوين بيئة SAP B1

يتضمن المشروع تكوين بيئة SAP B1 كاملة للاختبار والتطوير:

**بيئة الإنتاج:**
- **رابط طبقة الخدمة**: `https://192.168.11.22:50000/b1s/v1`
- **قاعدة بيانات الشركة**: `BS_NEW`
- **اسم المستخدم**: `BS2`
- **كلمة المرور**: `admin2007`

**بيئة العرض التوضيحي:**
- **رابط طبقة الخدمة**: `https://localhost:50000/b1s/v1`
- **قاعدة بيانات الشركة**: `SBODemoUS`
- **اسم المستخدم**: `manager`
- **كلمة المرور**: `manager`

### مجموعة Postman

تم تضمين مجموعة Postman شاملة في `docs/SAP_B1_POSTMAN_COLLECTION.json` لاختبار تكامل SAP B1. تتضمن المجموعة:

1. **طلب تسجيل الدخول**: المصادقة مع طبقة الخدمة في SAP B1
2. **إنشاء القيد اليومي**: أمثلة متعددة لعقود مختلفة
3. **اختبار الاتصال**: التحقق من الاتصال بـ SAP B1
4. **طلب تسجيل الخروج**: إغلاق الجلسة بشكل صحيح

**الميزات الرئيسية لمجموعة Postman:**
- إدارة الجلسة التلقائية مع ملف تعريف الارتباط B1SESSION
- متغيرات البيئة المُعدة مسبقاً
- عينات القيود اليومية للعقود: 658330, 434265, 384160, 228365, 353235, 411400, 409440
- أوصاف المذكرة باللغة العربية للتعريب المناسب
- تعيين رموز الحسابات الكاملة للمعايير المالية المصرية

### الاختبار باستخدام Postman

1. **استيراد المجموعة**: استورد `docs/SAP_B1_POSTMAN_COLLECTION.json` إلى Postman
2. **استيراد البيئة**: استورد `docs/SAP_B1_ENVIRONMENT.json` إلى Postman
3. **اختيار البيئة**: اختر البيئة المناسبة (الإنتاج أو العرض التوضيحي)
4. **تشغيل تسجيل الدخول**: نفذ طلب "Login" للمصادقة
5. **اختبار القيود اليومية**: شغل طلبات إنشاء القيود اليومية الفردية
6. **التحقق من الاتصال**: استخدم طلب "Test Connection" للتحقق من الاتصال
7. **تسجيل الخروج**: شغل دائماً طلب "Logout" عند الانتهاء

### استكشاف الأخطاء وإصلاحها

للحصول على معلومات مفصلة حول استكشاف الأخطاء وإصلاحها، راجع `docs/SAP_TROUBLESHOOTING.md`. تشمل المشاكل الشائعة:

- **فشل المصادقة**: تحقق من بيانات الاعتماد ورابط طبقة الخدمة
- **انتهاء مهلة الاتصال**: تحقق من اتصال الشبكة وإعدادات جدار الحماية
- **مشاكل تعيين البيانات**: تأكد من تطابق تنسيق بيانات Oracle مع الهيكل المتوقع
- **أخطاء القيود اليومية**: تحقق من رموز الحسابات وتكوين قاعدة بيانات الشركة
